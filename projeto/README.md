# Operação do Vermilion

As instruções de instalação, comando único de campeonato, opções, regras,
arquitetura e autoria estão no [README principal](../README.md).

```bash
cd /d/XADREZ/projeto && ./.venv/Scripts/python.exe -X utf8 jogar.py campeonato
```

Cada execução acompanha uma partida; dados em `dados/campeonato.sqlite3` e
LOGs em `dados/logs/`. Ao final informe os saldos físicos oficiais.
Testes e seus relatórios ficam em `tests/testes de campeonato/`.
